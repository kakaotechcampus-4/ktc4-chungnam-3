# REMEMBRALL - 충남대 3팀

저희 서비스는 저장만 하고 잊어버린 콘텐츠를, 필요한 순간에 AI가 대신 꺼내 주는 앱입니다.

## 소개

평소 SNS 사용자들은 인스타그램이나 유튜브에서 가고 싶은 장소를 저장해 두지만, 정작 그 장소 근처에 갔을 때는 저장했다는 사실조차 떠올리지 못합니다. <br>
REMEMBRALL은 공유받은 콘텐츠를 에이전트가 자동으로 요약 · 분류하고, 적절한 상황이 되었을 때 먼저 꺼내 주는 앱입니다.

## 동작 방식

1. **공유** - 인스타그램·유튜브에서 공유 시트로 콘텐츠를 보낸다.
2. **분석** - 에이전트가 내용을 3줄로 요약하고 장소·일정 정보를 추출한다.
3. **트리거 설계** - 이 콘텐츠를 언제 다시 보여줄지 결정한다. (위치 / 기간 / 시간대)
4. **대기** - 임베딩을 만들어 벡터 DB에 저장하고 조건이 충족될 때까지 기다린다.
5. **알림** - 저장한 장소 근처에 도착하거나 일정이 임박하면 먼저 알려 준다.
