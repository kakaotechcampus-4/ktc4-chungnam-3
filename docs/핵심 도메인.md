## 사용자 - Member

서비스를 사용하는 사용자를 관리합니다.  
개인 저장물을 소유하며, 트리거와 꺼내기 실행 및 알림은 개인 저장물을 통해 사용자와 연결됩니다.

## 콘텐츠 - Content

사용자가 공유한 YouTube 콘텐츠와 분석 결과를 관리합니다.  
동일한 영상은 `videoId`를 기준으로 멱등하게 처리하며, 여러 사용자가 저장해도 하나의 콘텐츠만 생성합니다.

## 개인 저장물 - PersonalSave

사용자가 콘텐츠를 저장한 관계를 관리합니다. `PersonalSave`가 존재하면 저장된 상태이며, 저장을 취소하면 해당 데이터를 삭제합니다. 공용 후보 제공 여부는 `PersonalSave`에 저장하지 않고 사용자의 유효한 `MemberConsent`를 기준으로 판단합니다.

## 장소 - Place

검증이 완료된 실제 장소를 관리합니다.  
장소명, 주소, 좌표 및 외부 장소 식별자 등을 저장하며, 검증되지 않은 장소 후보는 `Place`로 저장하지 않습니다.

## 콘텐츠와 장소 연결 - ContentPlace

콘텐츠에서 특정 장소가 어떻게 소개되었는지를 관리합니다.  
`Content`와 `Place`의 다대다 관계를 연결하며, 콘텐츠에 종속되는 장소 설명과 소개 순서 및 추출 신뢰도를 저장합니다.  
검증에 성공한 장소만 `ContentPlace`로 생성하며, 꺼내기 에이전트는 장소를 제안하는 이유와 콘텐츠 맥락을 구성할 때 이 정보를 사용합니다.

## 트리거 - Trigger

개인 저장물을 다시 꺼낼 위치 조건을 관리합니다.  
`PersonalSave`와 `ContentPlace`를 연결하며 지오펜스 반경과 활성 상태를 관리합니다.  
하나의 콘텐츠에 여러 장소가 있으면 장소별로 트리거를 생성할 수 있습니다.

## 꺼내기 실행 - RecallExecution

트리거로 시작된 꺼내기 에이전트의 실행을 관리합니다.  
검토한 후보, 도구 호출, 판단 과정과 최종 결과인 `PROPOSE` 또는 `NO_ACTION`을 기록합니다.

## 알림 - Notification

사용자에게 전달한 제안과 전송 결과를 관리합니다.  
중복 알림과 최근 알림 여부를 검사하는 근거로 사용하며, `NO_ACTION`인 실행에는 알림이 생성되지 않습니다.

# 보조 저장 구조

## 장소 후보 검증 기록 - PlaceCandidateLog

Gemini가 추출한 장소 후보와 장소 검색 결과를 기록합니다.  
검증 성공과 실패를 모두 기록하여 추출 오류, 검색 실패, 모호한 검색 결과 및 외부 API 오류를 구분합니다.  
분석 실행 식별자, 모델 버전, 프롬프트 버전, 추출된 장소명, 검색 질의, 검증 결과와 실패 이유를 기록하며 프롬프트와 장소 검증 과정의 개선에 활용합니다.  
운영과 분석을 위한 기록이므로 핵심 도메인에는 포함하지 않습니다.

## 회원 동의 기록 -MemberConsent

사용자의 공용 후보 제공 및 위치기반서비스 이용 동의 이력을 관리합니다.
동의 유형, 약관 버전, 동의 시각과 철회 시각을 기록하며, 하나의 사용자는 여러 동의 유형과 변경 이력을 가질 수 있습니다.
공용 후보는 `PUBLIC_CANDIDATE_CONTRIBUTION` 동의가 유효한 사용자의 `PersonalSave`만 대상으로 조회합니다.
위치기반서비스 동의를 철회하면 해당 사용자의 트리거를 비활성화하고 기기에 등록된 지오펜스를 제거합니다.

## 공용 후보

공용 후보는 별도의 `PublicPool` 테이블에 저장하지 않고 `PersonalSave`와 `MemberConsent`를 기준으로 조회합니다.
`PUBLIC_CANDIDATE_CONTRIBUTION`은 사용자가 저장한 콘텐츠를 다른 사용자의 후보 선정에 활용하는 것에 대한 선택 동의입니다. 동의 범위에는 현재 및 이후 생성되는 개인 저장물이 포함되며, 동의하지 않아도 개인 저장과 꺼내기 기능을 사용할 수 있습니다.
다음 조건을 모두 만족하는 콘텐츠만 공용 후보에 포함합니다.
- 유효한 공용 후보 활용 동의를 가진 사용자의 `PersonalSave`가 하나 이상 존재함
- 콘텐츠 분석이 정상적으로 완료됨

공용 후보 조회 결과에는 `Content`를 포함하며, 장소가 연결된 콘텐츠인 경우에만 `ContentPlace`와 `Place`를 함께 조회합니다. 저장한 사용자의 식별자, 저장 시각, 저장한 사용자 수 등 개인 저장 관계를 추론할 수 있는 정보는 다른 사용자에게 제공하지 않습니다.
사용자가 동의를 철회하거나 개인 저장물을 삭제하면 해당 저장물은 조회 시점부터 공용 후보 자격 계산에서 제외됩니다. 다른 동의 사용자의 개인 저장물이 남아 있는 경우에만 해당 콘텐츠를 계속 공용 후보로 사용할 수 있습니다.
공용 후보에는 원본 영상이나 자막을 복제하여 제공하지 않고, 서비스가 생성한 요약과 검증된 장소 정보 및 원본 링크만 제공합니다.
공용 후보에는 원본 영상이나 자막을 복제하지 않고, 서비스가 생성한 요약과 원본 링크를 제공합니다. 장소가 연결된 콘텐츠인 경우에는 검증된 장소 정보도 함께 제공합니다.

### 조회 조건

```sql
SELECT c.*
FROM content c
WHERE c.analysis_status = 'SUCCEEDED'
  AND c.source_status <> 'UNAVAILABLE'
  AND EXISTS (
      SELECT 1
      FROM personal_save ps
      JOIN member_consent mc
        ON mc.member_id = ps.member_id
      WHERE ps.content_id = c.id
        AND mc.consent_type = 'PUBLIC_CANDIDATE_CONTRIBUTION'
        AND mc.withdrawn_at IS NULL
  );
```

장소 보충 후보를 조회할 때는 검증된 `ContentPlace`가 연결된 콘텐츠만 추가로 선별합니다.
공용 후보 조회 성능이 실제로 문제가 될 경우 실행계획을 측정한 뒤 인덱스, 캐시 또는 물리화된 공용 풀 도입을 검토합니다.


# 주요 관계

```text
Member 1:N PersonalSave
Content 1:N PersonalSave
Content 1:0..1 PublicPool
Content 1:N ContentPlace
Place 1:N ContentPlace
PersonalSave 1:N Trigger
ContentPlace 1:N Trigger
Trigger 1:N RecallExecution
RecallExecution 0..1 Notification
```
