## 판정 방식

- 골든셋 장면을 실행하고 LLM Judge가 에이전트 평가 기준 문서로 채점한다.
## 완결 기준

1. **BAD 비율**: tune 24장면 3회, 72건 중 BAD가 1건 이하.
2. **에이전트 실패율**: 같은 72건 중 AGENT_FAILED가 2% 이하.
3. **확인용 장면**: holdout 6장면을 1회 실행해 BAD가 없음.
4. **도구 사용 결정**: BAD 비율과 토큰 비용을 보고 도구를 켤지 끌지 하나로 정해 설정에 반영.
5. **결과 기록**: 기준선부터 최종까지의 숫자를 표 한 장으로 남김.

## 현재 상태

|항목|도구 OFF 기준선|도구 ON|
|---|---|---|
|프롬프트|v1|v2, ID 규칙과 도구 안내만 변경|
|BAD|5 / 72|4 / 72|
|AGENT_FAILED|1 / 72|0 / 72|
|실행당 평균 토큰|1,840|3,971|
|에이전트 실행 시간 중앙값|7.66초|8.12초|

도구 ON의 BAD 4건 중 3건은 t18이다. 요약에 운영 기간이 끝났다고 적힌 팝업을 제안했다. 나머지는 사용자 상태를 단정하는 문구에서 나왔다.

## 이번 범위에서 하지 않는 것

다음은 해볼 만하지만 완결 기준에 필요하지 않다. 서비스 연결이 끝난 뒤 필요하면 다시 검토한다.

- 3점을 5점으로 올리는 튜닝
- 골든셋 장면 추가와 goodChoices 조정
- 입력에 요약 잘림 표시 추가
- 거리 도구 제거와 비교
- Judge 쌍대 비교

에이전트는 MVP로 완결하고, 남은 작업은 배포, 프론트 연동, 실제 푸시 수신 확인이다.
