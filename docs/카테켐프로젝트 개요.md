# 프로젝트 개요

## 1. 한 줄 소개
저장만 해두고 잊어버린 콘텐츠를 상황에 맞춰 다시 꺼내주는 서비스

## 2. 해결하려는 문제
- Shorts에서 장소를 발견해도 실제 방문으로 이어지지 않음
- 저장한 콘텐츠가 쌓이기만 하고 다시 확인하지 않음
- 사용자가 직접 장소명과 위치를 정리해야 함

## 3. MVP 범위
- YouTube Shorts 지원
- 영상에서 장소 정보 추출
- 실제 장소와 좌표 검증
- 장소 기반 트리거 생성
- 사용자의 위치와 조건이 맞으면 콘텐츠 알림
- 일정 기반 트리거와 Instagram은 제외

## 4. 사용자 흐름

### 저장
URL 공유
→ 영상 분석
→ 장소 탐색·검증
→ 필요하면 사용자 확인
→ 콘텐츠와 장소 트리거 저장

### 꺼내기
사용자 위치 변화
→ 주변에 저장한 장소 탐색
→ 꺼내기 에이전트가 알림 적합성 판단
→ 적합한 콘텐츠 알림

## 5. 주요 구성요소
- 모바일 앱
- Spring Boot 백엔드
- 저장 에이전트
- 꺼내기 에이전트
- YouTube Data API
- Vertex AI Gemini
- 장소검색 API
- 알림 서비스

## 6. 역할과 책임
- Spring: 인증, 콘텐츠 상태, DB, 트리거, 알림
- 저장 에이전트: 영상 분석, 장소검색, 장소 확정
- 꺼내기 에이전트: 현재 상황을 보고 알림 여부 판단
- 에이전트는 DB를 직접 수정하지 않음

## 7. 저장하는 데이터
- 원본 URL과 videoId
- 제목과 썸네일 등 메타데이터
- 짧은 요약
- 검증된 장소명·주소·좌표
- 위치 트리거

영상·음성·전체 자막은 저장하지 않는다.
