# 합성 데이터 기반 Bruno 회귀

운영 서버·기존 DB를 대상 주소로 받지 않는다. `run.sh`가 매번 새 PostgreSQL/pgvector 컨테이너,
무작위 localhost 포트, 테스트 전용 백엔드와 인증 토큰을 만들고 종료 시 정리한다.
Java 21, Node 22, Docker, Bash, curl, setsid가 있는 Linux에서 저장소 루트 기준으로 실행한다.

```bash
bash test/harness/run.sh
```

Bruno CLI는 4.3.0을 사용한다. 설치되어 있지 않으면 npx로 해당 버전을 실행한다.
로컬 캐시를 사용하려면 `BRUNO_CLI_JS=/절대경로/bru.js`를 지정할 수 있다.
기본값은 같은 DB/백엔드에서 컬렉션 4개를 두 차례 실행한다. 첫 확인 시에는 `BRUNO_REPEAT=1`을 지정할 수 있다.
동시에 여러 runner를 실행하면 보고서 파일명이 겹치므로 한 저장소에서는 순차 실행한다.

## 검증 범위

| 컬렉션 | 요청 파일 | 검증 |
| --- | ---: | --- |
| bruno-place-list | 26 | 내 장소 목록의 저장물·장소 쌍, 출처, 회원 격리, 중복 저장, 삭제 반영 |
| bruno-auth-device | 30 | FCM 실제 DB 저장·갱신·기기 간 이전, 세션 만료·재발급·로그아웃, 약관 버전 변경 |
| bruno-analysis-lifecycle | 68 | 실패 코드, 장소 없는 성공, 재저장 재시도, 중복 저장, 분석 중 삭제·다른 회원 보존, 멈춤 복구 |
| bruno-recall-retry | 48 | 판단 실패 재시도·한도·중복 방지, 제안 및 발송 상태, FCM 오류·무효 토큰 정리 |

172개는 로그인·데이터 준비·재조회·정리를 포함한 요청 파일 수다. 비동기 폴링이 반복되면 실제 요청 수는 더 많다.
기존 컬렉션과 일부 인증·준비 요청은 겹치지만 새 검증을 독립 실행하기 위해 포함했다.
기존 JUnit과의 역할 구분은 `SCENARIOS.md`에 기록한다.

## 대역과 실제 코드의 경계

`src/test/java/.../bruno`에만 있는 `BrunoHarness`를 Gradle `brunoHarness` 태스크로 실행한다.
이 클래스·설정·제어 경로는 `bootJar`에 포함되지 않는다. 운영 설정이나 인증 파일을 복사하지 않는다.

- 실제 코드: HTTP API, 세션 인증, 입력 검증, 동의 이력, 비동기 실행기, 분석 결과 반영, 임베딩 저장,
  개인 저장물·장소·트리거, 복구 스케줄러, 위치 이벤트 재시도, 제안 검증, 알림 상태 전이.
- 테스트 대역: 영상 분석기, 장소 검색·좌표 확정·카카오 검증, 임베딩 벡터 생성, RecallAgent, PushSender.
- 분석 오류·timeout은 분석기 경계의 고정 결과로 재현한다. 실제 429/500 HTTP 응답, SDK 파싱,
  네트워크 타임아웃·재시도 자체를 검증한 결과가 아니다. 실제 연동은 기존 수동 컬렉션으로 확인한다.
- `SENT`는 합성 PushSender의 성공 응답이다. 실제 FCM 접수·휴대폰 수신·OS 지오펜스는 검증하지 않는다.
- 약관 버전 검증은 기존 동의/현재 버전 표시, 이전 버전 재동의 거절, 최신 버전 저장을 확인한다.
  현재 서비스가 명시적으로 보장하지 않는 자동 지오펜스 차단을 가정하지 않는다.
- `recover`는 서버 재시작을 흉내 내는 대신 오래된 분석 시각을 준비하고 실제 복구 메서드를 호출한다.
  실제 프로세스 강제 종료·재시작이나 대기열 경계 조건은 JUnit/별도 운영 검증 범위다.

## 격리와 제어

테스트 백엔드는 localhost에만 바인딩하고 DB 이름이 `bruno_regression`인 경우에만 시작한다.
Spring/Flyway 초기화 전에 환경변수의 DB URL을 검사하고, CLI로 다른 설정을 덮어쓰는 실행도 거절한다.
테스트 전용 `/__bruno/control`은 생성된 32바이트 이상 토큰을 `X-Bruno-Control`로 받아야 사용할 수 있다.
임의 SQL은 받지 않는다. 데이터 초기화·합성 데이터 생성·대역 모드 변경·관찰 등 정해진 동작만 허용한다.
관찰 API가 반환하는 FCM 토큰은 이 임시 DB에 생성된 가짜 토큰이다.
컬렉션은 제어 API 초기화가 성공하지 않으면 다른 요청을 실행하지 않는다.

일반 GUI에서 운영 환경을 선택해 실행하지 않는다. 수동 디버깅이 필요하면 runner가 만든 임시 환경을 사용한다.
실행 중 Ctrl+C나 테스트 실패 시에도 trap이 해당 Java 프로세스·Docker 컨테이너/볼륨·임시 환경 파일을 정리한다.
SIGKILL이나 호스트 장애처럼 trap을 실행할 수 없는 종료는 자동 정리를 보장하지 않는다.

## 보고서와 CI

JUnit XML과 테스트 백엔드 로그는 `test/harness/reports/`에 보관하고 Git에서는 제외한다.
요청·응답 본문과 헤더는 Bruno 보고서에서 제외한다. `--verbose`로 세션·제어 토큰을 출력하지 않는다.
GitHub Actions의 `Bruno seeded regression`이 develop 대상 PR에서 이 구성을 실행한다.
실제 키가 필요한 수동 컬렉션을 자동 실행 목록에 넣지 않는다.
보고서 생성은 성공 판정이 아니다. 실패·오류 수가 0인지 확인한다.
