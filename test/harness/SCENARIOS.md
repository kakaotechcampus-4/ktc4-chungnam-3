# 기존 검증과 추가 범위

| 범위 | 기존 | 이번 추가 |
| --- | --- | --- |
| 내 장소 | PersonalSaveIntegrationTest의 API/저장 검증 | Bruno에서 같은 장소의 여러 출처·회원 격리·삭제까지 연결 |
| 세션 | 기본 Bruno 재로그인·로그아웃, 인증 JUnit | 만료 상태 준비 후 실제 HTTP 차단·재로그인, 로그아웃 DB 상태 |
| FCM | 기본 Bruno의 상태 코드·입력 검증 | 저장값·갱신값·토큰 이전 후 양쪽 상태·로그아웃 정리 관찰 |
| 동의 | v1 저장·철회·오류 후 유지 | v1→v2 변경, 구버전 거절 후 기록 보존·최신 재동의 |
| 분석 | 실제 영상 저장과 정상 분석 수동 검증, JUnit 파이프라인 | 분석기 대역 실패 결과부터 HTTP 상태·저장 정리까지 연결 |
| 삭제 | 분석 완료 후 삭제 | 분석 중 중복 저장·마지막 저장 삭제·다른 회원 저장 유지 |
| 복구 | StaleAnalysisRecoveryScheduler와 관련 JUnit | 오래된 ANALYZING 준비 후 실제 복구와 재저장 API 연결 |
| 위치 이벤트 | 기본 접수와 차단 정책, 실제 LLM 수동 검증 | 실패한 동일 이벤트 재시도·한도·완료 이벤트 재전송 시 DB/호출 수 |
| 발송 | 실제 LLM 알림 생성·열기, PushSender JUnit | DB 상태·토큰 정리를 포함한 합성 발송 실패별 회귀 |

다음은 이번 테스트로 완료 처리하지 않는다: 실제 모델 품질, 외부 HTTP/SDK 자체의 실패 처리,
운영 서버 재시작 복구, 실제 휴대폰 FCM 수신, iOS/Android 대량 지오펜스 선택, 동시성 경쟁 전체.
공용 후보 답변 반복 테스트와 다른 회원 트리거 생성 JUnit 보강도 이 컬렉션 추가와 별개다.

수동 외부 API 결과는 주차 PR에 실행 날짜·커밋·환경·범위·성공/실패·알려진 제외 항목을 기록한다.
과거 실행 결과를 최신 커밋의 통과 결과로 옮겨 적지 않는다. CI 결과와 실제 기기 결과를 구분한다.
