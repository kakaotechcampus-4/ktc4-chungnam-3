
# 작성 규칙

- **ID**: `도메인-번호` 형식 (예: `AUTH-03`)
- **우선순위**
  - P0: 핵심 흐름과 보안. 실패하면 릴리스할 수 없음
  - P1: 오류 처리와 예외 흐름
  - P2: 경계값과 형식 세부사항
- **상태**
  - 가능: 지금 바로 테스트 가능
  - 토큰: 실제 카카오 토큰이 있어야 함
  - 시드: 미리 넣어둔 데이터가 있어야 함
  - 미구현: API가 아직 없음

| ID | 시나리오 | 절차 → 기대 결과 | 우선 | 상태 |
| --- | --- | --- | --- | --- |
| AUTH-01 | 정상 로그인 | 유효한 카카오 토큰으로 로그인 → 200, `sessionToken`과 미래 시각의 `sessionExpiresAt` | P0 | 토큰 |
| AUTH-02 | 발급받은 세션으로 보호 API 사용 | AUTH-01 토큰으로 FCM 등록 → 204 | P0 | 토큰 |
| AUTH-03 | 로그아웃하면 세션 즉시 폐기 | 로그아웃 204 → 같은 토큰으로 호출 → 401 `INVALID_SESSION` | P0 | 토큰 |
| AUTH-04 | 재로그인하면 이전 세션 폐기 | 2회 로그인 → 첫 번째 토큰 401, 두 번째 토큰 정상 | P0 | 토큰 |
| AUTH-05 | 같은 카카오 계정은 같은 회원 | 재로그인 후 이전 저장물이 그대로 보임 | P0 | 토큰, 미구현 |
| AUTH-06 | 세션 없이 보호 API 호출 | 헤더 없음, `Bearer `만 있고 값 없음 → 401 | P0 | 가능 |
| AUTH-07 | 변조된 세션 | `Bearer abc` → 401 | P0 | 가능 |
| AUTH-08 | 잘못된 카카오 토큰 | 임의 문자열로 로그인 → 401 `INVALID_KAKAO_TOKEN` | P1 | 가능 |
| AUTH-09 | 로그인 요청 형식 오류 | 토큰 누락, 빈 문자열, 깨진 JSON → 400 `INVALID_REQUEST` | P1 | 가능 |
| AUTH-10 | 만료된 세션 | 만료 시각이 지난 세션으로 호출 → 401 | P1 | 시드 |
| AUTH-11 | 로그인 말고는 공개 경로 없음 | `GET /api/auth/kakao` 등 다른 메서드 → 401 | P2 | 가능 |

# EVT: 위치 이벤트

이 API는 이벤트를 무시하는 경우에도 항상 202를 반환합니다. 그래서 "알림이 생겼는지"는 알림 목록 API가 생긴 뒤에 그쪽에서 확인합니다.

| ID | 시나리오 | 절차 → 기대 결과 | 우선 | 상태 |
| --- | --- | --- | --- | --- |
| EVT-01 | 정상 진입 → 알림 생성 | 트리거가 있는 장소에 ENTER → 202 → 알림 1개 생성 | P0 | 토큰, 시드 |
| EVT-02 | DWELL 이벤트 | DWELL → 202, ENTER와 같은 처리 | P1 | 토큰, 시드 |
| EVT-03 | 같은 이벤트 중복 전송 | 같은 `triggerEventId`로 2회 → 둘 다 202, 알림은 1개만 | P0 | 토큰, 시드 |
| EVT-04 | 쿨다운 | 알림을 받고 10분 안에 다른 장소 이벤트 → 202, 알림 없음 | P1 | 토큰, 시드 |
| EVT-05 | 오래된 이벤트 | `eventOccurredAt`이 30분보다 이전 → 202, 알림 없음 | P1 | 토큰, 시드 |
| EVT-06 | 트리거 없는 장소 | 저장하지 않은 `placeId` → 202, 알림 없음 | P1 | 토큰 |
| EVT-07 | 다른 사용자의 장소 | B가 A만 저장한 장소로 이벤트 → 202, 알림 없음 | P0 (보안) | 토큰, 시드 |
| EVT-08 | location 생략 | location 없이 → 202 (선택 항목) | P2 | 토큰 |
| EVT-09 | 필수값 누락 | `placeId`, `triggerEventId`, `eventType`, `eventOccurredAt` 각각 누락 → 400 | P1 | 토큰 |
| EVT-10 | 잘못된 eventType | `EXIT`, 소문자 `enter` → 400 | P1 | 토큰 |
| EVT-11 | 값 범위 오류 | 위도 91, 경도 181, 정확도 음수, UUID가 아닌 값 → 400 | P2 | 토큰 |

| NOTI-08 | 없는 알림 | 임의 UUID로 조회 또는 열람 → 404 `NOT_FOUND` | P1 | 토큰 |
