# 실제 외부 연동 배포 gate

`test/external/run.mjs --jar 검증할.jar` 전용 컬렉션이다. 실제 비용이 발생한다.
실행기가 빈 임시 DB와 실제 백엔드를 만들고 관찰 도구·환경을 제공한다. 운영 URL을 수동으로 넣지 않는다.
준비와 필수 Secrets/Variables, 실패 시 배포 차단 및 실제 기기 검증의 구분은
[릴리스 안내](../../.github/deploy/README.md)를 참고한다.

11개 요청 파일: 로그인 → 저장 → 실제 분석 폴링 → 임베딩/장소 관찰 → 동의 → 위치 이벤트 → LLM trace/결과 → 알림 조회 → 정리.
NO_ACTION이면 알림 조회만 건너뛴다. 정상 NO_ACTION을 PROPOSE 품질 검증 통과로 집계하지 않는다.
실행은 새 분석 1회와 새 이벤트 1회이며, 실패할 때 성공할 때까지 재시도하지 않는다.
