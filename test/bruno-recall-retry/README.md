# bruno-recall-retry

판단기·푸시 대역과 실제 실행·알림 DB 상태로 재시도 한도·중복 방지·발송 실패를 검증한다.

총 65개 요청이다. 재시도 한도 및 각 푸시 오류 시나리오는 새 회원으로 로그인·동의·저장하여
앞 시나리오의 발송 이력과 분리한다. 같은 회원의 동일 이벤트 재전송은 기존 실행을 유지하고,
발송 성공한 장소에 새 이벤트를 보내도 실행·알림·판단기·푸시 호출이 늘지 않는지 별도로 확인한다.
최근 발송 이력 차단을 비활성화하거나 기존 이력을 지우지 않는다. 마지막 reset에서 전체 임시 데이터를 정리한다.

운영 서버 대상 컬렉션이 아니다. 저장소 루트에서 Linux 환경의 다음 명령으로 실행한다.

    bash test/harness/run.sh

임시 환경 생성·보호 장치·대역의 범위·보고서 확인 방법은 [하네스 안내](../harness/README.md)를 참고한다.
개별 요청에는 앞 단계의 실행 중 변수가 필요하므로 준비 없이 단독 실행하지 않는다.
