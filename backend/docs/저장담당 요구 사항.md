# YouTube 콘텐츠 추출 담당 요구사항

추출 결과는 아래 DTO 구조에 맞춰 반환한다.

## 반환해야 할 내용

- **처리 결과:** `SUCCESS`, `PARTIAL`, `FAILED` 중 하나를 반환한다.
    
- **분석 버전:** 사용한 분석 파이프라인, 모델과 프롬프트 버전을 반환한다.
    
- **콘텐츠 요약:** 의미 검색에 사용할 수 있도록 핵심 주제, 소개 대상, 주요 특징과 영상에서 명시된 추천 상황·제약을 간결하게 반환한다. 장소가 없어도 요약은 남긴다.
    
- **장소 후보 목록:** 상호명, 지점·지역 단서와 해당 장소에 관한 설명을 반환한다. 여러 장소는 각각 분리하고 고유한 `candidateId`를 부여한다.
    
- **날짜·시간 정보:** 행사·팝업 등 기간이 있는 콘텐츠는 확인된 시작일·종료일과 시간을 반환한다. 관련 장소가 있다면 해당 장소의 `candidateId`를 참조한다.
    
- **근거와 불확실성:** 각 장소·날짜 정보의 출처와 불확실한 항목을 표시한다.
    

장소나 행사가 없는 영상은 해당 목록을 비운 `SUCCESS` 결과로 반환한다.

## 반환 DTO

### `YouTubeContentExtractionResultDto.java`

```java
import java.util.List;

/**
 * YouTube 콘텐츠 추출 작업의 최종 반환값.
 */
public record YouTubeContentExtractionResultDto(

        /** 전체 처리 결과 */
        ExtractionStatus status,

        /** 분석에 사용한 파이프라인·모델·프롬프트 버전 */
        AnalysisMetadataDto analysisMetadata,

        /** 콘텐츠의 핵심 내용과 명시된 특징·상황·제약을 정리한 요약 */
        String summary,

        /** 요약 과정에서 확실하게 판단하지 못한 내용 */
        List<String> summaryUncertainties,

        /** 영상에서 추출한 장소 후보 목록 */
        List<PlaceCandidateDto> placeCandidates,

        /** 영상에서 추출한 행사·기간·시간 정보 */
        List<TemporalInfoDto> temporalInfos,

        /** PARTIAL 또는 FAILED인 경우의 실패 정보 */
        FailureInfoDto failure

) {
}
```

### `PlaceCandidateDto.java`

```java
import java.util.List;

/**
 * 영상에서 추출한 하나의 장소 후보.
 * 실제 장소 검증 전이므로 확정된 장소로 취급하지 않는다.
 */
public record PlaceCandidateDto(

        /** 같은 추출 결과 안에서 장소를 구분하기 위한 임시 ID */
        String candidateId,

        /** 상호 또는 장소의 기본 이름 */
        String name,

        /** 확인된 지점명. 확인할 수 없으면 null */
        String branchName,

        /** 도시, 구, 동 등 장소 식별에 도움이 되는 지역 단서 */
        String regionHint,

        /** 영상에서 해당 장소를 어떻게 소개했는지 정리한 내용 */
        String description,

        /** 영상에서 명시한 방문 순서. 순서가 없으면 null */
        Integer suggestedOrder,

        /** 장소 정보를 확인한 근거 목록 */
        List<EvidenceDto> evidence,

        /** 지점명이나 지역 등 확실하게 판단하지 못한 내용 */
        List<String> uncertainties

) {
}
```

## 반환 규칙

- 모든 목록은 값이 없더라도 `null`이 아닌 빈 배열로 반환한다.
    
- `analysisMetadata`는 처리 결과와 관계없이 항상 반환한다.
    
- `analysisVersion`은 분석 결과에 영향을 주는 파이프라인이 변경될 때 갱신한다.
    
- `modelName`과 `promptVersion`에는 실제 사용한 값을 반환한다.
    
- `candidateId`는 한 번의 추출 결과 안에서 중복되지 않아야 한다.
    
- `relatedPlaceCandidateIds`는 같은 결과의 `candidateId`만 참조할 수 있다.
    
- 날짜가 여러 장소에 공통으로 적용되면 관련된 모든 `candidateId`를 참조한다.
    
- 장소와 관계없는 날짜이거나 연결을 확인할 수 없다면 `relatedPlaceCandidateIds`를 빈 배열로 반환한다.
    
- 확인되지 않은 날짜·시간·지점 정보는 추정하지 않고 `null`로 반환한다.
    
- `originalText`에는 날짜·시간이 표현된 내용을 보존한다.
    
- `suggestedOrder`는 영상에서 방문 순서가 명시된 경우에만 반환한다.
    
- `SUCCESS`일 때 `failure`는 `null`이다.
    
- `PARTIAL` 또는 `FAILED`일 때 `failure`에 실패 정보를 반환한다.
    

## 실패 시 전달할 정보

- 실패 단계
    
- 확인된 API 상태 코드 또는 오류 종류
    
- 오류 내용
    
- 일부만 추출했다면 확인된 범위
    

분석 실패를 `장소 후보 없음`으로 처리하지 않는다.
