# YouTube 콘텐츠 추출 담당 요구사항

Gemini 추출 결과는 아래 `YouTubeContentExtractionResultDto` 구조에 맞춰 반환한다.

이 DTO는 **추출 단계의 결과**다. 저장 파이프라인은 장소 처리까지 마친 뒤, 문서 마지막에 정의한 **최종 결과**를 백엔드에 반환한다.


## 반환해야 할 내용

- **처리 결과:** `SUCCESS`, `PARTIAL`, `FAILED` 중 하나를 반환한다.
- **분석 버전:** 사용한 분석 파이프라인, 모델과 프롬프트 버전을 반환한다.
- **콘텐츠 요약:** 핵심 주제, 소개 대상, 주요 특징과 영상에서 명시된 추천 상황·제약을 간결하게 반환한다. 장소가 없어도 요약은 남긴다.
- **장소 후보 목록:** 상호명, 지점·지역 단서와 영상에서 해당 장소를 소개한 내용을 반환한다. 여러 장소는 각각 분리한다.
- **날짜·시간 정보:** 기간이 있는 콘텐츠는 확인된 날짜와 시간을 반환한다. 

장소나 기간 정보가 없는 정상 영상은 해당 목록을 비운 `SUCCESS` 결과로 반환한다.

## 추출 상태와 저장 연계

`YouTubeContentExtractionResultDto.status`는 추출 단계의 결과를 나타낸다.

- `SUCCESS`: 추출 작업이 오류 없이 끝났다. 장소 후보가 없어도 `SUCCESS`다.
- `PARTIAL`: 활용할 수 있는 요약은 확보했지만 추출 작업의 일부가 완료되지 않았다.
- `FAILED`: 활용할 수 있는 분석 결과를 확보하지 못했다.

 저장 파이프라인은 추출 과정의 오류를 구분해 최종 실패 코드를 만든다. 특히 추출 상태가 `FAILED`라는 이유만으로 원본 영상을 `UNAVAILABLE`로 판단하지 않는다. 원본 접근 불가는 호출 과정에서 실제로 확인된 경우에만 기록한다.

저장 파이프라인은 추출 결과를 받은 뒤 장소 검색·검증 등 후속 작업을 진행한다. 전체 처리 결과를 백엔드에 전달한다.

## 추출 DTO

### `YouTubeContentExtractionResultDto.java`

```java
import java.util.List;

/**
 * YouTube 콘텐츠 추출 단계의 반환값.
 */
public record YouTubeContentExtractionResultDto(

        /** 추출 단계의 처리 결과 */
        ExtractionStatus status,

        /** 분석에 사용한 파이프라인·모델·프롬프트 버전 */
        AnalysisMetadataDto analysisMetadata,

        /** 콘텐츠의 핵심 내용과 명시된 특징·상황·제약을 정리한 요약 */
        String summary,

        /** 영상에서 추출한 장소 목록 */
        List<PlaceCandidateDto> placeCandidates,

        /** 영상에서 추출한 행사·기간·시간 정보 */
        List<TemporalInfoDto> temporalInfos,
        
        /** PARTIAL이거나 FAILED 일 경우, 그 이유 */
		ExtractionFailureCode failureCode

) {
}
```

### `AnalysisMetadataDto.java`

```java
/**
 * 분석 결과를 생성한 환경의 버전 정보.
 */
public record AnalysisMetadataDto(

        /** 분석 파이프라인 전체 버전 */
        String analysisVersion,

        /** 실제 사용한 모델명 */
        String modelName,

        /** 실제 사용한 프롬프트 버전 */
        String promptVersion

) {
}
```

### `PlaceCandidateDto.java`

```java
import java.util.List;

/**
 * 영상에서 추출한 하나의 장소 후보.
 * 실제 장소 검증 전이므로 확정된 장소로 취급하지 않는다.
 */
public record PlaceCandidateDto(

        /** 같은 추출 결과 안에서 장소를 구분하기 위한 임시 ID */
        String candidateId,

        /** 상호 또는 장소의 기본 이름 */
        String name,

        /** 확인된 지점명. 확인할 수 없으면 null */
        String branchName,

        /** 도시, 구, 동 등 장소 식별에 도움이 되는 지역 단서 */
        String regionHint,

        /** 영상에서 해당 장소를 어떻게 소개했는지 정리한 내용 */
        String description


) {
}
```

### `TemporalInfoDto.java`

```java
import java.time.LocalDate;
import java.time.LocalTime;
import java.util.List;

/**
 * 행사, 팝업, 축제 등 기간이 있는 정보.
 */
public record TemporalInfoDto(

        /** 날짜·시간이 적용되는 행사 또는 대상의 이름 */
        String subject,

        /** 영상에 표현된 원래 날짜·시간 내용 */
        String originalText,

        /** 이 기간과 연결되는 장소 후보의 candidateId 목록 */
        List<String> relatedPlaceCandidateIds,

        /** 확인된 시작일. 확인할 수 없으면 null */
        LocalDate startDate,

        /** 확인된 종료일. 확인할 수 없으면 null */
        LocalDate endDate,

        /** 확인된 시작 시간. 확인할 수 없으면 null */
        LocalTime startTime,

        /** 확인된 종료 시간. 확인할 수 없으면 null */
        LocalTime endTime

) {
}
```

### `ExtractionStatus.java`

```java
public enum ExtractionStatus {

    /** 요청한 추출을 정상적으로 완료함 */
    SUCCESS,

    /** 일부 정보는 추출했지만 전체 추출은 완료하지 못함 */
    PARTIAL,

    /** 유효한 분석 결과를 만들지 못함 */
    FAILED
}
```

### ExtractionFailureCode

```java
public enum ExtractionFailureCode {
    VIDEO_UNAVAILABLE,        // 원본 접근 불가를 확인함
    EXTRACTION_API_ERROR,     // YouTube 또는 Gemini 호출 실패
    EXTRACTION_RESULT_ERROR  // 응답 변환 실패
}
```


## 추출 DTO 반환 규칙

- 모든 목록은 값이 없더라도 `null`이 아닌 빈 목록으로 반환한다.
- `SUCCESS`이면 `failureCode`는 `null`이고, `PARTIAL` 또는 `FAILED`이면 해당 실패 코드를 반환한다.
- `analysisMetadata`는 처리 결과와 관계없이 항상 반환한다.
- `analysisVersion`은 분석 결과에 영향을 주는 파이프라인이 변경될 때 갱신한다.
- `modelName`과 `promptVersion`에는 실제 사용한 값을 반환한다.
- `candidateId`는 한 번의 추출 결과 안에서 중복되지 않아야 한다.
- `relatedPlaceCandidateIds`는 같은 결과의 `candidateId`만 참조할 수 있다.
- 날짜가 여러 장소에 공통으로 적용되면 관련된 모든 `candidateId`를 참조한다.
- 장소와 관계없는 날짜이거나 연결을 확인할 수 없다면 `relatedPlaceCandidateIds`를 빈 목록으로 반환한다.
- 확인되지 않은 날짜·시간·지점 정보는 추정하지 않고 `null`로 반환한다.
- `originalText`에는 영상에 표현된 날짜·시간 내용을 보존한다.
- 장소 후보가 없는 정상 결과와 추출 실패를 구분한다.

## 저장 파이프라인의 최종 반환 계약

저장 파이프라인은 추출과 장소 처리를 마친 뒤 백엔드에 최종 결과를 반환한다. 백엔드는 `Content`의 최종 상태와 분석 정보를 저장하고, 검증된 장소만 `Place`·`ContentPlace`에 반영한다.

### 최종 상태

- `SUCCESS`: 영상 해석과 필요한 후속 작업이 오류 없이 끝났다. 장소가 없거나 사용자 확인이 필요한 경우도 포함한다.
- `PARTIAL`: 활용 가능한 요약을 확보했지만 추출 일부 또는 장소 검색·검증 등 필요한 작업에서 오류가 발생했다.
- `FAILED`: 활용할 분석 결과를 확보하지 못했다.

장소 검색 결과가 없거나 결과가 모호한 것은 장소 검색 API 오류와 구분한다.

### 실패 코드

기존 HTTP 응답용 `ErrorCode`와 별도로 파이프라인 실패 코드를 사용한다.

| 최종 상태     | 실패 코드                          | 상황                                   |
| --------- | ------------------------------ | ------------------------------------ |
| `SUCCESS` | 없음                             | 정상 처리, 장소 없음, 사용자 확인 필요              |
| `PARTIAL` | `PLACE_SEARCH_API_ERROR`       | 요약 확보 후 LocationIQ 호출 실패             |
| `PARTIAL` | `PLACE_VERIFICATION_API_ERROR` | 요약 확보 후 장소 검증 호출 실패                  |
| `FAILED`  | `EXTRACTION_API_ERROR`         | 활용할 결과를 얻기 전 YouTube 또는 Gemini 호출 실패 |
| `FAILED`  | `VIDEO_UNAVAILABLE`            | 원본 영상의 접근 불가가 확인됨                    |
| `FAILED`  | `EXTRACTION_RESULT_ERROR`      | 응답 변환 실패로 활용할 결과를 얻지 못함              |

메타데이터 조회와 Gemini 호출 중 정확히 어디에서 장애가 발생했는지는 파이프라인 내부 로그에 남긴다. `Content.lastAnalysisErrorCode`에는 외부 API의 원시 메시지가 아닌 위의 실패 코드를 저장한다.

### 장소 결과

각 장소에는 추출 단계의 `description`, LocationIQ 결과를 기준으로 저장할 장소명·주소·좌표·장소 식별자, 현재 `Place` 설계에서 요구하는 카카오 검증 장소 식별자를 전달한다.
기간 정보는 추출 DTO에 유지한다. 현재는 별도 행사 엔티티를 만들지 않으며, 사용자에게 필요한 내용은 콘텐츠 요약에 반영한다.
