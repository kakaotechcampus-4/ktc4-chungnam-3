
**배경**

위치 이벤트가 올 때마다 에이전트를 실행하면 두 가지 문제가 생긴다.

- 저장 장소가 몰린 동네를 걸으면 가게 앞을 지날 때마다 이벤트가 와서 알림이 연달아 간다.
- 가까운 장소 이벤트가 몇 초 간격으로 오면 에이전트가 동시에 여러 번 돌아 LLM 비용이 중복된다.

**결정**

회원 단위 실행 쿨다운 하나로 제한한다.

- 이벤트를 받으면 Member 행을 잠그고, 이 회원의 최근 RecallExecution이 쿨다운 기간 안에 있으면 새 실행을 만들지 않는다.
- NO_ACTION과 FAILED를 포함해 모든 실행을 센다.
- 기본값은 2시간이며 설정값으로 둔다.

**검토한 대안**

| 대안         | 판단                                                                                     |
| ---------- | -------------------------------------------------------------------------------------- |
| 장소 쿨다운     | 최근 보낸 제안에 들어간 장소를 기준으로 막아 반복 방지에 가장 맞지만 장소의 범위등, 고려할 사항이 많아서 MVP에서는 이는 적합하지 않다고 판단하였다. |
