
- `SUCCESS`: 영상 해석과 필요한 후속 작업이 오류 없이 끝남. 장소 없음이나 사용자 확인 필요도 정상 결과.
- PARTIAL: 영상 해석 결과는 확보했지만, LocationIQ 호출 등 후속 작업이 오류로 중단됨.
- `FAILED`: 메타데이터 조회 또는 Gemini 영상 해석에 실패해 활용할 분석 결과를 확보하지 못함.

- 저장·추출 담당과 실패 계약 확정: `FAILED`일 때 **원본 접근 불가가 확인된 경우**와 **일시적 호출 실패**를 `failure.errorType` 등으로 구분한다.
- `ContentAnalysisResultService` 수정: 추출 DTO를 받자마자 최종 상태로 바꾸는 현재 동작을 제거하고, 장소 검증 등 후속 작업이 끝난 뒤 `SUCCESS`·`PARTIAL`·`FAILED`를 확정한다.


|상황|상태|`errorCode`|
|---|---|---|
|요약을 얻기 전 YouTube·Gemini 호출 장애|`FAILED`|`EXTRACTION_API_ERROR`|
|원본 접근 불가가 확인됨|`FAILED`|`VIDEO_UNAVAILABLE`|
|요약 확보 후 장소 검색 호출 장애|`PARTIAL`|`PLACE_SEARCH_API_ERROR`|
|장소 없음·사용자 확인 필요|`SUCCESS`|`null`|
