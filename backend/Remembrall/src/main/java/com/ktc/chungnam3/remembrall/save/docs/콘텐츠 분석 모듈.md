# 콘텐츠 분석 모듈 (Module A)

"저장 파이프라인.md" 7장에서 정리된 모듈 분담 중 Module A(콘텐츠 분석) 담당 작업 계획.
Module B(장소 확정 + 조율) 쪽 계획은 `저장 파이프라인.md` 참고.

## 1. 분담 경계

경계는 `YouTubeContentExtractionResultDto` 하나. Module A의 산출물이 Module B의 입력이 된다.

| | Module A (콘텐츠 분석, 이 문서) | Module B (장소 확정 + 조율) |
|---|---|---|
| 담당 패키지 | `save/youtube/`, `save/analysis/` | `save/place/`, `save/confirm/`, `save/dto/`, `SavePipelineService`/`Controller` |
| 책임 | URL→videoId, YouTube 메타데이터·댓글 조회, Gemini 분석(프롬프트·스키마), 구조화 출력 파싱 | LocationIQ 검색, 후보 필터링·판정, 되묻기 정책, 전체 흐름 조율, API |
| 산출물 | `YouTubeContentExtractionResultDto` (상태·제목·요약·장소후보·기간정보·실패코드) | `SavePipelineResultDto` (확정 장소 / 되묻기 / 없음) |

## 4. 팀 논의 현황

`저장 파이프라인.md`의 "역할 재분배 논의" 안건 관련. 2026-10-06~07 종훈님·서민규님과 대화로 대부분 해결됨.

| 항목 | 상태 |
|---|---|
| `evidence`/`uncertainties`/`suggestedOrder`/`summaryUncertainties` 제거 | **해결** — 종훈님·서민규님 확인, 서민규님이 올린 갱신된 계약 문서로 반영 완료 |
| 실패 코드 매핑 (`FailureStage`↔`ContentAnalysisFailureCode`) | **해결** — 중간 번역 단계 자체가 없어짐. `ExtractionFailureCode`(VIDEO_UNAVAILABLE/EXTRACTION_API_ERROR/EXTRACTION_RESULT_ERROR)를 추출 단계에서 바로 반환하도록 계약이 바뀜. `GEMINI_CALL`(이전 개념)은 영상 문제가 아니라 Gemini 호출 자체의 확률적 불안정성(20~50%, 5장 참고)으로 확인돼 `EXTRACTION_API_ERROR`로 통일 |
| `title`/`sourceStatus` 연결 | **해결** — title은 계약에 필드로 추가. sourceStatus는 `failureCode`(`VIDEO_UNAVAILABLE` 여부)로 유추 가능해 별도 필드 없이 제거 |
| `category`를 콘텐츠 단위로 할지 장소 단위로 할지 | **미해결** — 실측 중 한 영상에 음식점+소품샵이 섞여 나온 사례 발견(예: "오뛰그" 소품샵). 서민규님도 "한 영상에 장소가 여러 개일 수도, 아예 없을 수도 있어 애매하다"고 보류. category 분류 리스트 자체(카페/맛집/술집/쇼핑 등, 공공데이터 업종코드 I2/G2와 매칭됨)는 합의됐으나 단위 결정 전까진 구현 보류 |
| `placeCandidates` 배열 ↔ 결과 단수 필드 | 종훈님 쪽(`SavePipelineResultDto`) 작업 — 멘토님이 리스트 구조 제안하심, 에스더 쪽 액션 아이템 없음 |

## 5. 품질 측정 결과 (2026-10-06, 실제 Gemini 호출 10건)

- **장소 추출 정확도**: 59/59 (100%, A등급 — 상호명+지점명까지 정확) — 직접 영상 시청 후 전수 대조
- **1차 시도 성공률**: 8/10 (80%) / **재시도 포함 최종 성공률**: 10/10 (100%)
- **소요시간**: 평균 59초, 최소 24초, 최대 189초
- **중요 발견**: 1차 실패 2건을 처음엔 `VIDEO_ACCESS`(영상 자체 문제)로 추정했으나, 재시도해보니 둘 다 결국 성공함. 같은 영상을 다시 돌려도 성공까지 걸리는 시도 횟수가 매번 다름(1번/2번/3번) — **영상별 문제가 아니라 Gemini 호출 자체가 랜덤하게 20~50% 실패하는 것으로 보임.** 재시도 로직은 최소 2~3회를 권장.
- 상세 데이터(영상별 비교표, 재시도 기록): `AI/평가셋.md`
