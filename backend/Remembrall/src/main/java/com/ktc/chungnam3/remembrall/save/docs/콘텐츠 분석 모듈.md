# 콘텐츠 분석 모듈 (Module A)

"저장 파이프라인.md" 7장에서 정리된 모듈 분담 중 Module A(콘텐츠 분석) 담당 작업 계획.
Module B(장소 확정 + 조율) 쪽 계획은 `저장 파이프라인.md` 참고.

## 1. 분담 경계

경계는 `YouTubeContentExtractionResultDto` 하나. Module A의 산출물이 Module B의 입력이 된다.

| | Module A (콘텐츠 분석, 이 문서) | Module B (장소 확정 + 조율) |
|---|---|---|
| 담당 패키지 | `save/youtube/`, `save/analysis/` | `save/place/`, `save/confirm/`, `save/dto/`, `SavePipelineService`/`Controller` |
| 책임 | URL→videoId, YouTube 메타데이터·댓글 조회, Gemini 분석(프롬프트·스키마), 구조화 출력 파싱 | LocationIQ 검색, 후보 필터링·판정, 되묻기 정책, 전체 흐름 조율, API |
| 산출물 | `YouTubeContentExtractionResultDto` (요약·장소후보·기간정보·근거·불확실성) | `SavePipelineResultDto` (확정 장소 / 되묻기 / 없음) |

## 2. 현재 상태

| 상태 | 내용 |
|---|---|
| 완료 (develop 병합됨) | `YoutubeUrlParser`, `YoutubeMetadataClient`(메타데이터+채널소유자 고정댓글 조회), `VideoContentAnalyzer` 뼈대(Gemini 3.6 Flash 호출, 프롬프트 v2, JSON 스키마 강제 출력, 파싱) |
| 확인된 공백 | `VideoContentAnalyzer`가 `YoutubeMetadataClient`를 아직 호출하지 않음 — 제목·설명·해시태그·고정댓글이 프롬프트에 전달되지 않고, 영상 자체만 보고 판단함 |
| 검증 | `VideoContentAnalyzer`에 대한 품질 검증(정확도 측정)이 아직 없음 — `PlaceResolverTest`/`ConfirmPolicyTest`와 달리 테스트 없음 |

## 3. 작업 계획

| 순서 | 내용 | 상태 |
|---|---|---|
| ① | `VideoContentAnalyzer`가 `YoutubeMetadataClient` 결과(제목·설명·태그·고정댓글)를 프롬프트에 포함하도록 연결 | 이번 PR |
| ② | 로컬 실행 환경 세팅 — 팀 GCP 프로젝트(Vertex AI)로 바로 연결. 사전 확인: 해당 프로젝트에 Vertex AI API 활성화 여부, 계정 IAM 권한(Vertex AI User 등) | 다음 PR |
| ③ | 보유 중인 Shorts 샘플로 소규모 실행 검증 | 다음 PR |
| ④ | 평가셋 구축 후 정식 품질 측정(정확도·비용·소요시간·실패율), 프롬프트 개선 | 이후 |

## 4. 셋이 합의해야 하는 것 (Module A 단독 결정 불가)

`저장 파이프라인.md`의 "역할 재분배 논의" 안건에 아래 추가.

| 항목 | 내용 | 누구랑 |
|---|---|---|
| `extraction/` DTO 계약 | `evidence`/`uncertainties`/`suggestedOrder`를 실제로 저장·활용할지 (현재 생성만 되고 소비하는 곳 없음), `category` 필드 추가 여부 | 에스더 + 종훈 + 저장담당 요구 사항.md 작성자 |
| `placeCandidates` 배열 ↔ 결과 단수 필드 | 영상 한 건에서 장소 후보가 2개 이상 나올 때 `SavePipelineResultDto`(`place`/`confirm` 단수)로 어떻게 표현할지 | 에스더 + 종훈 |
| 실패 코드 매핑 | `FailureStage`(Module A) ↔ `ContentAnalysisFailureCode`(백엔드 저장) 매핑표 부재 | 에스더 + 백엔드 담당 |
| `ContentSourceStatus`/`title` 연결 | `YoutubeMetadataClient`가 이미 판단·보유한 값을 `Content` 엔티티에 채우는 연결부 부재 | 에스더 + 백엔드 담당 |
